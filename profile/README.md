## 👋 Who we are

**TXSoft** is a startup focused on building, managing and optimizing technology solutions for companies and professionals. This organization brings together TXSoft's engineering work: the **Core Engine**, the platform's microservices, internal tools and ongoing research.

## 🧭 What we build

| Initiative | What it is |
| --- | --- |
| **TXSoft Development Platform (BackFlow)** | SaaS platform to create, generate, orchestrate and run back-ends, with a visual builder, AI for code and tests, and built-in CI/CD and hosting. |
| **Core Engine – Ignis** | Infrastructure core: API Gateway, Data Engine, Query/Command Engines and messaging that power the whole ecosystem. |
| **Core Engine – Prometheus** | "Community" engine with ready-made modules and security guardrails, the foundation for software built on BackFlow by third parties. |
| **TXSoft Account** | A single account to access every TXSoft product. |
| **TX Cloud** | The cloud infrastructure the platform runs on. |
| **Artificial Intelligence** | AI research and products applied across the ecosystem (Feynman, SophIA, IAnalytics). |

- **Containerized microservices** orchestrated with Kubernetes, with self-healing and horizontal scaling.
- **Polyglot CQRS**: writes in Java/Quarkus for transactional integrity, reads in Go for speed.
- **gRPC between services, GraphQL at the edge**, for strong typing inside and zero over-fetching outside.
- **Event-driven** with Kafka and multi-level caching with Redis.
- **CI/CD with security validation** (SAST/DAST) and tests before any deploy.

1. Read the README of the repository you are going to work on.
2. Open an issue before large changes, using the available templates.
3. All code goes in through a reviewed Pull Request.
4. Questions? Talk to the engineering team.
