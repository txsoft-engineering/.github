## 👋 Quem somos

A **TXSoft** é uma startup especializada em criar, gerenciar e otimizar soluções tecnológicas para empresas e profissionais. Esta organização reúne o trabalho de engenharia da TXSoft: o **Core Engine**, os microsserviços da plataforma, as ferramentas internas e as pesquisas em andamento.

## 🧭 O que construímos

| Iniciativa | O que é |
| --- | --- |
| **TXSoft Development Platform (BackFlow)** | Plataforma SaaS para criar, gerar, orquestrar e executar back-ends, com builder visual, IA para código e testes, CI/CD e hospedagem integrados. |
| **Core Engine – Ignis** | Núcleo de infraestrutura: API Gateway, Data Engine, Query/Command Engines e mensageria que sustentam todo o ecossistema. |
| **Core Engine – Prometheus** | Motor "community", com módulos prontos e travas de segurança, base para os softwares criados no BackFlow por terceiros. |
| **TXSoft Account** | Conta universal para acessar todos os produtos TXSoft. |
| **TX Cloud** | Infraestrutura de nuvem onde a plataforma roda. |
| **Inteligência Artificial** | Pesquisa e produtos de IA aplicados ao ecossistema (Feynman, SophIA, IAnalytics). |

- **Microsserviços em contêineres** orquestrados com Kubernetes, com auto-recuperação e escala horizontal.
- **CQRS poliglota**: escrita em Java/Quarkus pela integridade transacional, leitura em Go pela velocidade.
- **gRPC entre serviços, GraphQL na borda**, para tipagem forte por dentro e zero over-fetching por fora.
- **Orientado a eventos** com Kafka e cache multinível com Redis.
- **CI/CD com validação de segurança** (SAST/DAST) e testes antes de qualquer deploy.
