## 👋 Quiénes somos

**TXSoft** es una startup especializada en crear, gestionar y optimizar soluciones tecnológicas para empresas y profesionales. Esta organización reúne el trabajo de ingeniería de TXSoft: el **Core Engine**, los microservicios de la plataforma, las herramientas internas y las investigaciones en curso.

## 🧭 Qué construimos

| Iniciativa | Qué es |
| --- | --- |
| **TXSoft Development Platform (BackFlow)** | Plataforma SaaS para crear, generar, orquestar y ejecutar back-ends, con builder visual, IA para código y pruebas, y CI/CD y hosting integrados. |
| **Core Engine – Ignis** | Núcleo de infraestructura: API Gateway, Data Engine, Query/Command Engines y mensajería que sostienen todo el ecosistema. |
| **Core Engine – Prometheus** | Motor "community", con módulos listos y barreras de seguridad, base para el software creado en BackFlow por terceros. |
| **TXSoft Account** | Una cuenta universal para acceder a todos los productos TXSoft. |
| **TX Cloud** | Infraestructura en la nube donde se ejecuta la plataforma. |
| **Inteligencia Artificial** | Investigación y productos de IA aplicados al ecosistema (Feynman, SophIA, IAnalytics). |

- **Microservicios en contenedores** orquestados con Kubernetes, con autorrecuperación y escalado horizontal.
- **CQRS políglota**: escritura en Java/Quarkus por la integridad transaccional, lectura en Go por la velocidad.
- **gRPC entre servicios, GraphQL en el borde**, para tipado fuerte por dentro y cero over-fetching por fuera.
- **Orientado a eventos** con Kafka y caché multinivel con Redis.
- **CI/CD con validación de seguridad** (SAST/DAST) y pruebas antes de cualquier deploy.
